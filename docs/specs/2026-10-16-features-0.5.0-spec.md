# Features, release 0.5.0
Status: Ready, except the two open decisions below

Scope: issues #46 (crash guards), #47 (foreign player colour), #48 (tactics positions), #56 (options screen), #57 (full player search) and #58 (idle CPU). #49 waits for Q174.

## Problem
The original 2002 game stops on a few rare faults: a news item with no text, some transfer offers and some squad updates. In our port these faults do not stop the game, but they go on with wrong data. The tactics screen shows each player's position only when the player switches the view, so a player out of position is easy to miss. The squad screen shows "Fgn" for a foreign player only when no other status hides it, so a player does not see at a glance who counts against a foreign player limit. Every option of the Bosman Edition is a line in the settings file, and a player must edit a text file to change one.

## Solution
Release 0.5.0 adds guards for the original's known crashes, a position column on the tactics screen in every view and mode, a colour for players who count against the next match's foreign player limit, and an options screen in the game. The player search can show every player, as an option that is off by default. No feature changes a match result or a game decision while the player makes the same clicks.

## User stories
1. As a player in a long game, I want the game to skip a broken news item, so that a fault of the 2002 game does not spoil my save.
2. As a player, I want transfers and squad updates that hit a known fault of the original to be skipped safely, so that the game does not go on with wrong data.
3. As a player who does not want changes to the original's rules, I want the guards to act only where the original would crash.
4. As a player, I want to see each player's position on the tactics screen when it opens, so that I see who plays out of position.
5. As a player in classic mode, I want the same position column, so that classic is not the poor mode.
6. As a player, I want the names of players who count against the foreign player limit of my next competitive match in their own colour on the squad screen and the tactics screen.
7. As a player in July, I want the colour to use my first league or cup match, because friendlies have no restrictions.
8. As a player scouting another club, I want the same colour on that club's squad screen.
9. As a player who knows the original, I want the "Fgn" status to stay.
10. As a player, I want to switch the Bosman Edition's options on and off in the game, from the start screen and from the side bar's Game Options.
11. As a player who changes the display mode, I want the screen to tell me that it applies at the next start.
12. As a player who edits settings.txt by hand, I want the file to stay the store and keep its comments.
13. As a player who wants to find any player in the world, I want an option that makes the player search show every player, not only players my manager knows.

## Decisions
- **Same game (Q152):** unchanged. Each feature is checked with the same clicks, option on and off. Opening the options screen changes later days, as opening any screen does, so a same-save check of the options screen compares two runs that both open it.
- **Crash guards (Q176, Q177, research):** always on, no option. They guard the original at the Null News Item text renderer, the StupidNULLPointer sites, the two transfer offer sites, the squad manager site (danny_bhoy67), the staff records sites (vascobenny), the transfer manager site, virtual staff 195, the competition crash (Teebo78) and the World Cup NULL site. Each guard tests for NULL only where the original would read, write or call through NULL. In a game that does not reach the fault, the path is the same. The Netherlands guard (woerd86) is left out until its caller is read.
- **Rule changes not in 0.5.0 (Q178):** "Unlock your creativity", the marking and position clamp, the cash fix above 2.1 billion and the Argentina jump change results. They are out of this release.
- **Full player search (Q179):** a new option, off by default. On: the player search lists every player, as Nick's "find all players" patch does. It changes no computer decision, but it changes memory after a search.
- **Leap-year date of birth (Q180, research):** no code fault. The data stores 29 February as day 59, which shows as 1 March. The game cannot recover the true date. It leaves the issue.
- **Tactics positions (Q182 to Q186):** the option `match_columns` keeps its name and now also covers the tactics screen outside a match. The Condition view shows status, position and condition, in and out of a match. The Match Rating view keeps what 0.2.0 ships. Classic shows the column too, with narrower column weights. Positions are yellow, as in the Position(s) view. No out-of-position colour in 0.5.0.
- **Foreign player colour (Q187 to Q193):** a new option `foreign_colours`, on by default. A name gets light violet (RGB565 0xCC7F) when the rule of the club's next competitive fixture counts the player: a non-EU rule and he is non-EU, or a foreign rule and he is foreign. The age rule is ignored. It shows on the squad screen and the tactics screen, for the player's club and for other clubs. The original's "Fgn" status stays. It reads the game's own rule and nationality functions and changes only a text colour.
- **Options screen (Q173, Q194 to Q200):** a "Bosman Edition Options" screen in the style of the original's Game Settings: each row shows the current value framed in yellow and the other values as buttons. It opens from the start screen and from the side bar's Game Options popup area, after Game Settings. It shows every option. `save_folder` is read-only, with the note "change it in settings.txt". `display`, `save_folder` and `sound` show "Applies at the next start". A change is written to the settings file at once. The settings file stays the store, with its comments.
- **#49 (Q174, research):** both screens open in about 33 ms and step once per click since 0.1.0. Nick's patch slows each click and raises the top asking price from 30 to 60 million, which changes decisions. Open: Q174.
- **Idle CPU (Q175):** the game uses one full core while idle. A short sleep when no input waits is added only if `--same-save` and `--match` give equal results with and without it.

## Testing
- **Same-save seam:** `tests/smoke/smoke_run.py --same-save` from `start.sav` and `prematch.sav`, option on and off, for every slice. Equal saves pass.
- **Recompiled-function seam:** for each crash guard, recompile only the guarded function with a driver, as `tests/recomp/test_load.py` does. Feed a NULL pointer with page 0 filled with 0xCC: the guard skips. Feed a good pointer: the result equals the Unicorn run of the original.
- **Screen seam:** smoke screenshots of the tactics screen and the squad screen in classic, widescreen and HD from `start.sav`, before and after. For the colour, Arsenal's next Premier Division fixture (3 non-EU) and one club with a foreign rule.
- **Options seam:** `ctest -R options` for the new write path. A smoke run that opens the options screen, switches an option, and reads settings.txt back.
- Test games run in parallel. A run that fails on timing is run again alone first.

## Out of scope

- An out-of-position colour on the tactics screen (Q185).
- The age rule in the foreign colour.
- A text entry for `save_folder`.
- The leap-year date of birth (data, not code).
