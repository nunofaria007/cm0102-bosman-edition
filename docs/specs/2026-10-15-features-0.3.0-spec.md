# Features, release 0.3.0
Status: Ready

## Problem
Release 0.2.0 has the comforts most players asked for, but players still lose time and careers to small things. A bad save can end a career. The window opens at its default size each time. Condition and morale need reading, not a glance. Holiday cannot stop before the next match. The fastest commentary is still slow. Save names say nothing about the club or date. On Windows, two shortcuts do not work. Linux and Steam Deck players cannot play at all. Players also cannot pick a team with one click, and they cannot choose the original 2001/02 data.

## Solution
Release 0.3.0 adds these features without a change to any match result or game decision, except the team that the player or the assistant picks. Every new option is a line in the settings file. The release adds a Linux download that also runs on the Steam Deck.

## User stories
1. As a Windows player, I want Ctrl+[ to go Back and F11 to switch full screen, because Windows takes the Windows-key forms.
2. As a player, I want the game to keep my last three saves of each file, so that one bad save never costs a career.
3. As a player, I want the window to open where and how I left it, full screen included.
4. As a player who moved the window to a monitor that is now unplugged, I want it to open on a screen I can see.
5. As a player, I want condition percentages and morale words in colour, so that I see tired or unhappy players at a glance.
6. As a player who likes attribute colours but not condition colours, I want to switch each set off by itself.
7. As a player, I want a holiday that ends the day before my next match, so that I pick the team myself.
8. As a player whose club has no fixture left in the season, I want "Until next match" to tell me there is none, not to run on.
9. As a player, I want a commentary speed faster than the game's fastest.
10. As a player, I want the same match result at every commentary speed.
11. As a player, I want Save As to suggest a name such as "Arsenal 2001-07-20", which I can still change.
12. As a player, I want saves with dated names to sort in date order.
13. As a player on Linux or a Steam Deck, I want a download that starts without setup.
14. As a Steam Deck player, I want the trackpad to work as the mouse.
15. As a player, I want an Assistant drop-down on the squad screen with Pick best team, Pick most match-fit team, Pick under-21 team and Clear squad.
16. As a player who picks an under-21 team without eleven young players, I want the gaps filled with the best older players.
17. As a player starting a new game, I want to choose the original 2001/02 data or the updated 2002/03 data.
18. As a player loading an old save, I want it to load as before, whatever data it started with.
19. As a player who asked for a feature on Reddit, I want a credit in the release post when it ships.

## Decisions
Settled in the interviews of 2026-10-15 (Q64 to Q67 for the drop-down, Q68 to Q97 for the rest).

- **Scope (Q68):** 0.3.0 holds #12, #26, #27, #28, #29, #30, #31, #34, #35 and #39. #22 (with the polygon analyser, Q83), #32 (now the HD mode at 1920x1080, Q82) and #33 move to 0.4.0. #36 (2D match view, label `maybe`), #37 (Android) and #38 (iOS) have no milestone.
- **Faithful logic:** no feature may change match results or game decisions. Picking a team is the one exception, as before. #30 and #31 must pass a same-save check over a played match.
- **Windows keys (#26, Q73):** on Windows, Back is Ctrl+[ and full screen is F11. The Windows-key forms go. The Mac keys stay as they are.
- **Save backups (#27, Q74):** before the game writes a save over an existing file, the old file moves to `backups/` in the save folder. Three copies of each save stay. The oldest goes. Option `save_backups`, on by default. The game's own save code does not change.
- **Remember the window (#28, Q75):** on quit, the runtime stores the window size, position and full screen state. The next start uses them. If the stored position is off every connected screen, the window opens at 1280x800 in the middle of the main screen. Option `remember_window`, on by default.
- **Condition and morale colours (#29, Q76):** condition below 75% red, 75 to 89% amber, 90% or more green. Morale words use the same three bands, from the game's own order of morale words. Option `condition_colours`, on by default, separate from `attribute_colours`.
- **Holiday until next match (#30, Q77):** a new item "Until next match" on the holiday popup ends the holiday the day before the next fixture of the player's club. The existing holiday lengths stay. When the club has no fixture left, the item does nothing and says so.
- **Faster commentary (#31, Q78):** one new step on the commentary speed list, twice as fast as the game's fastest.
- **Save names (#34, Q79):** Save As suggests "Club YYYY-MM-DD" from the player's club and the game date. The player can edit it.
- **Linux and Steam Deck (#35, Q80):** one x86-64 AppImage with the clean files. The Steam Deck runs it in its default desktop controls, with the trackpad as the mouse. No Deck-only code in 0.3.0.
- **Assistant drop-down (#12, Q64 to Q67):** on the squad screen, Clear Squad becomes an Assistant drop-down in the style of Filter: Pick best team, Pick most match-fit team, Pick under-21 team, Clear squad. Best team uses the game's own assistant judgement if research shows it can run outside match setup. If it cannot, our own picker uses the game's position ratings and condition. Under-21 fills gaps with the best older players. Branch `worktree-agent-a8d8677cceced7e8f` (commit 8d5345b) has match-setup code to reuse. Do not merge that branch.
- **Data set choice (#39, Q89 to Q97):** the Setup Game screen gets a "Database" choice for each new game, also stored as `database = 3.9.68` in the settings file. Two data sets: "2001/02, original data (3.9.60)" from the free release and "2002/03, updated data (3.9.68)", the default. 3.9.65 joins only if its official patch holds full data files. Both data sets ship in the downloads. A save loads as before, whatever data it started with. If the 3.9.68 original cannot run a new game on 3.9.60 data, #39 moves to 0.3.1 (Q93). If a download could not ship the 3.9.60 data, the player would point the game at their own copy (Q92). The research found no reason for that, because the 3.9.60 data comes from the same free release as the clean files.
- **Release timing (Q93):** if #39 needs more time than the rest, 0.3.0 ships without it and #39 follows as 0.3.1.
- **Credits:** `docs/requests.md` lists who asked for what. The release post credits each requester whose feature ships.

Research facts used here (2026-10-15, by an Opus research agent):
- The free release is 3.9.60 with 2001/02 data from September 2001.
- 3.9.65 (7 December 2001) has "game and data updates". An archived official copy exists, and nobody has checked whether it holds full data files.
- 3.9.67 and 3.9.68 change the data to 2002/03 with the same 2001 start date.
- The table versions and record sizes of 3.9.60 and 3.9.68 data match. That does not prove that the 3.9.68 original loads the 3.9.60 data.

## Testing
- **Smoke run** in both modes must pass after every slice. It now uses wait steps.
- **Same-save check over new games** (`--same-save`): the five runs play at the same time, about 80 s. A new option that must not change the game adds a run.
- **Match same-save check (new, slice 1):** from the saved test game before the Basel friendly, the script plays the match and saves a fixed number of days after it. Two runs that differ only in one option must give identical saves. #30 and #31 use it.
- **Saved test games:** `tests/fixtures/fixtures.py play` starts a check from a save, so most checks skip the new game and the database load.
- **Screen checks:** drawing features dump the screen in both modes. The slice shows before and after screenshots of about 800 px.
- **Options:** `ctest -R options` covers each new option line and its default.
- **Manual checks by Max:** the Windows keys on a Windows PC, the window memory on two screens, and the Steam Deck.
- Test games run in parallel. If a parallel run fails on timing, run it alone before you call it a bug.

## Out of scope
- #22 player comparison, squad depth, best XI and the polygon analyser (0.4.0).
- #32 HD mode (0.4.0) and #33 print to PDF (0.4.0).
- #36 2D match view, #37 Android, #38 iOS.
- Steam Deck controls beyond the default desktop controls.
- A data set made by fans, or any data that does not come from an official file.
- Any change to the match engine, the AI decisions or the database contents.
