How to install

Mac

  1. Download the .dmg file and open it.
  2. Drag the game onto the Applications folder.
  3. Open the game. If macOS says it cannot check it, go to System Settings, then Privacy & Security. Scroll down and click Open Anyway.

Windows

  1. Download the Setup.exe file and run it.
  2. If a blue box says "Windows protected your PC", click More info, then Run anyway.
  3. Click through the installer. The game appears in the Start menu and on the desktop.

Questions

Is this official?

No. It is a fan project with no link to Sports Interactive, SEGA, Eidos or Square Enix. Eidos made the game free to download in 2008, and this download includes those game files.

How does it run on a modern computer?

Every instruction of the original Windows program is translated into C and compiled for your machine. No emulator runs underneath, so the match engine and the rest of the game are the ones from 2002.

Where are my saved games?

On a Mac: ~/Library/Application Support/cm0102. On Windows: %APPDATA%\cm0102. A new release does not change this folder.

How do I get the 800 × 600 layout back?

Open settings.txt in the save folder and change the line to display = classic. Then start the game again.

Is the database updated?

No. It is the 2001/02 season with the last official patch, 3.9.68. Fan patches and newer databases are not included.

Something does not work

Open an issue on GitHub. Say which computer you use and what you clicked before the problem.
